# Seedance 3.0

Seedance 3.0 is a free AI video generator for 4K cinematic videos from text and images. It supports multi-shot narrative, native audio sync, and consistent characters.

Try the [AI video generator](https://seedance3ai.video/) online.

## Example

`prompt_builder.py` is a small helper that formats a prompt string before you paste it into Seedance 3.0:

```
python3 prompt_builder.py "a lighthouse at dawn" --style cinematic
```
